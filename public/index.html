STEP 1 Decoded Packets

Each frame is dissected through Ethernet / IP / TCP / UDP up to the application layer (SIP, PFCP, HTTP/2 SBI, RTP).
#Time (s)SourceDestinationProtoInterfaceInfo

STEP 2 Extracted Feature Vectors

Packets are grouped into protocol flows; each flow becomes a feature vector — request / response counts, final status, retransmissions, missing responses and duration — the input to the classifier.
FlowTypeInterfacePktsReqRespFinal StatusRetransMissing RespDuration

STEP 3 Random Forest Classification

A 10-estimator ensemble votes on the flow; the majority decides SUCCESS or FAILURE with a confidence score.

STEP 4 RAG — 3GPP Retrieval

The anomaly is turned into a query and matched by vector similarity against an embedded 3GPP corpus (TS 23.501, TS 23.502, TS 29.244, TS 29.500, TS 24.229, TS 33.501).

STEP 5 AI Root-Cause Explanation

The classified anomaly and the retrieved spec clauses are synthesised into a grounded, human-readable diagnosis with a recommended action.
